# WeaHR documents

- `WeaHR_Product_Overview_VI.docx`: bản mô tả sản phẩm hiện tại dành cho khách hàng.
- `WeaHR_Legacy_Overview.pdf`: tài liệu PDF cũ, chỉ dùng để đối chiếu.
- `product-brochure/assets/`: ảnh nguồn để tạo lại bản mô tả sản phẩm.

Tạo lại tài liệu DOCX:

```powershell
python scripts/build_product_brochure.py
```

File kết quả được ghi vào `docs/WeaHR_Product_Overview_VI.docx`.
